Core Characteristics of a Robot

Every robot has three core capabilities — remember them with the acronym ICO:

I
Input
Perceive the environment using sensors
C
Compute
Make decisions using a program
O
Output
Take action using motors / servos
💡
Exam Tip (2021Q9): Multi-target coordinated motion tasks test all three ICO layers working together. Make sure you can trace which layer (I, C, or O) handles each part of the task.

Robot Joints & Degrees of Freedom (DOF)

A degree of freedom (DOF) is one independent direction in which a robot can move. Think of it like asking: "In how many ways can this part move on its own?"

S
Shoulder 3 DOF
Forward/back · Left/right · Rotate
E
Elbow 1 DOF
Bend only
W
Wrist 2 DOF
Up/down · Rotate
Total = 3 + 1 + 2 = 6 DOF ✅

Translational vs Rotational

  • 📐 Translational (3)
    Slide along X · Y · Z axis
  • 🔄 Rotational (3)
    Rotate around X · Y · Z axis

Common Joint Types

Joint TypeMotionDOFReal-World Example

Prismatic (P)Slides along an axis1Drawer, hydraulic cylinder
Spherical (S)Rotates in any direction3Human shoulder

Gear Ratio Formula (Preview — full detail in Chapter 2)

$$i = \frac{n_1}{n_2} = \frac{z_2}{z_1}$$
i— gear ratio (transmission ratio)
n₁— drive gear speed (RPM)
n₂— driven gear speed (RPM)
z₁— teeth on drive gear
z₂— teeth on driven gear
🐢
Small → Large
Slow down
Gain torque (more force)
🐇
Large → Small
Speed up
Lose torque

Structural Design Principles

Stability Rules

⬇️
1. Low center of gravity — place heavy components at the bottom of the robot
↔️
2. Wide support base — wider chassis = harder to tip over
⚖️
3. Symmetric design — balance weight equally on left and right sides

Lightweight Materials

🔩
Steel
Strong but heavy
Heavy
✈️
Aluminium Alloy
Similar strength, ~½ the weight
Recommended
🚀
Carbon Fibre
Lightest & strongest option
Best (expensive)

Modular Design

🧩
Independent Subsystems
Design each part independently for easy repair and upgrades
🔗
Standardised Interfaces
Use the same screws and connectors throughout — no special tools needed
📝 Chapter Summary — Key Points to Remember
Degrees of Freedom Max 6 (3 translational + 3 rotational)
Differential drive Same speed → straight · Different speeds → turn · Opposite → spin in place
Gear ratio $$i = \frac{z_2}{z_1} = \frac{n_1}{n_2}$$
Stability Low COG + wide base = harder to tip over
Mecanum wheels Special angled rollers that allow full omnidirectional movement
