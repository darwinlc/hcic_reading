Open Loop vs Closed Loop Control

❌ Open-Loop
📤 Command sent
↓
⚙️ Actuator acts
↓
🤷 Result ignored
No feedback — hopes for the best!

e.g. "Run motor for 1 second" — doesn't check if target was reached

✅ Closed-Loop
📤 Command sent
↓
⚙️ Actuator acts
↓
📡 Sensor checks result
↓
🔁 Error corrected → repeat
Continuously self-corrects!

e.g. Encoder measures position, motor keeps adjusting until target is reached

🏆
Competition tip: Closed-loop control is far more accurate and is used extensively in robot competitions. When in doubt, use feedback!
3.4 📊

PID Control

PID is the most widely used closed-loop control algorithm in robotics. Each letter is a different way of correcting error:

P
Proportional
Bigger error → stronger correction. Reacts immediately to how far off you are.
"How far off am I? Push back by that much."
I
Integral
Fixes persistent small errors that P alone can't fully correct over time.
"I've been slightly off for a while — build up correction gradually."
D
Derivative
Predicts the trend and eases off before overshooting the target.
"I'm correcting too fast — slow down before I overshoot!"

PID Formula

$$u(t) = K_p \cdot e(t) \;+\; K_i \cdot \int e(t)\,dt \;+\; K_d \cdot \frac{de(t)}{dt}$$
u(t)control output (e.g. motor speed)
e(t)current error = target − actual
Kpproportional gain
Kiintegral gain
Kdderivative gain

Simplified Version

Output  =  Kp × current error
        +  Ki × accumulated error (history)
        +  Kd × rate of change of error (trend)

Tuning Steps for Competition

Step 1:  Start with P only (Ki = Kd = 0) — tune until it basically works
Step 2:  Add D to reduce oscillation and overshooting
Step 3:  If there's still a steady error, add a small I term

PWM Motor Control

PWM = Pulse Width Modulation — controls motor speed by varying how long the signal is "on" vs "off" in each cycle. Exam: 2021Q5

$$\text{Duty Cycle} = \frac{t_{\text{high}}}{T} \times 100\%$$
thightime signal is HIGH (on) in one period
Ttotal period length
